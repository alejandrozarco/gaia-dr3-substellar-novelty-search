These ZTF-quiescent depths *underestimate* the true eclipse depth because: (a) ZTF

The eclipse is real and ZTF g-r-i are consistent with quiescent CV colors; the *true* depth

**Bottom line on TESS eclipses**:

- The TESS S98 eclipse profile resolved 298 distinct orbital cycles, of which 63 occurred in
  quiescence and 235 during intermediate (decline / pre-outburst rise) states.
- The **median in-eclipse flux deficit at quiescence is 71% of OOE**, and individual
  in-eclipse cadences reach as low as **0.06 e-/s vs OOE ≈ 4 e-/s** — i.e., a near-total
  eclipse (>98% flux removed) of the bright accretion-disk + WD core.
- The pipeline's 24.9% averaged phase-fold depth from `cv_period_tess_2026_05_28.py` is the
  *bin-averaged* eclipse depth (averaging over phase bins, including the partial-eclipse
  shoulders); the **per-eclipse measured depth (71% median) is the true eclipse depth** and
  is the definitive evidence that the orbital period detection is real.

**Outburst evidence in S98**: 4 distinct outburst events in 52 days, each lasting ~9-10 days
with ~5-day gaps. This is consistent with a **superoutburst followed by a series of normal
outbursts** — the canonical signature of an SU UMa-type DN. The S98 baseline is too short
to confirm the standard SU UMa superhump pattern, but the cadence is right and the location
in the period-gap reinforces the SU UMa classification.

## 5. Spectroscopic data

**SDSS DR17 spectroscopy**: no spectrum at this position (SpecObj cone returned 0 rows within
10"). Despite 4 SDSS photometric epochs, the target was never observed spectroscopically by
the SDSS-I/II/III/IV/V plug plates. This is a follow-up gap that can and should be filled.

**LAMOST DR10/DR9/DR8 (LRS)**: 0 entries within 10" across all available LAMOST DR
catalogs queried via Vizier. No publicly-archived medium-resolution spectrum exists.

**SDSS-V** has not yet observed this position (SDSS-V is not yet released for this region).

**No prior spectroscopic classification exists**. The CV-class identification rests entirely
on photometric grounds:
- Outburst signature (Drake+ 2014, CSS091109) — 1 detection at V=15.4 in 88 CSS observations
- Coppejans+ 2016 classification "DN" — based on the CSS outburst light curve
- Pre-outburst rise and decline visible in the deep SDSS-II epochs
- This work: 7 documented optical outbursts including a 7-day g=14.4 superoutburst
- This work: TESS-resolved 71% (median) eclipse — high inclination eclipsing CV

The expected emission-line signature for a 3-hr-period DN is:
- **Strong, double-peaked Hα** (FWZI 2000-3000 km/s; canonical for high-inclination CV disks)
- **He I 5876, 6678, 7065** emission
- **He II 4686 emission** (weak, but distinguishes magnetic CV / nova-like)
- Possible **N III/C III λ4640-4650 "Bowen blend"** if disk-irradiated

These all remain to be measured with a single 1-hr quiescent spectroscopy run on an 8-m class
telescope (SALT, VLT/X-shooter, Keck) — see §9.

## 6. CV classification via combined evidence

**Class verdict**: cataclysmic variable, dwarf nova subclass, SU UMa candidate, deeply
eclipsing at high inclination.

| Diagnostic | Observation | CV interpretation |
|---|---|---|
| Orbital period | 180.05–180.77 min = 3.00–3.01 hr | In the canonical **CV period gap** (2.1-3.2 hr; Knigge 2006) |
| Variability range | 5+ mag (g_min=14.4 → g_max=21.3) | Consistent with DN outburst amplitude (3-7 mag typical) |
| Outburst cadence | ~300 d (median ZTF) | Consistent with SU UMa subclass at 3-hr period |
| Superoutburst | 7-day, g=14.4 (Sep 2023) | Direct evidence of SU UMa-class superoutbursts |
| Optical colors | u-g = -0.3, g-r = +0.3 | In CV color box (u-g < 0.4, g-r < 0.5) |
| UV excess | Strong (u-g <0) | Hot accretion disk + WD primary |
| IR colors | W1-W2 = 0.94 | Modest red excess from donor M-dwarf + hot-spot |
| Eclipse depth (TESS, median quiescent) | 71% | Near-total eclipse → high inclination, i ≳ 80° |
| Eclipse profile width (TESS BLS dur) | 1.8 min (binned, lower bound) | Consistent with deep eclipse of WD + inner disk |
| Eclipse duty cycle (TESS half-depth) | 18% of period = 32 min | Wider envelope = stream/hot-spot ingress/egress |
| Gaia phot_variable_flag | VARIABLE | Confirmed photometric variability across DR3 visits |
| classprob_dsc_combmod_quasar | 0.994 | **False positive**: DSC model classified this CV as a QSO based on UV-excess + variability; this is a known DSC failure mode for CVs (Pala 2020, Inight 2023). |
| in_qso_candidates | True | Same DSC false positive |
| Position in period gap | 3.013 hr | Period gap (2-3 hr); ~20% of CVs sit at the gap boundaries (Knigge 2011) |
| Disk vs polar | No detected B field, optical orbital-period detection w/o spin period | **disk-accreting CV** (not a polar) |

**Subtype rationale**: The combination of (a) frequent outbursts (~yearly), (b) 7-day
superoutburst observed in 2023, (c) orbital period at 3.0 hr (i.e. *just above* the lower edge
of the 2.1-3.2 hr period gap, which is also the upper boundary of the SU UMa population), and
(d) outburst amplitude of 5+ mag at peak, makes this a clear **SU UMa candidate**. Confirmation
requires a superhump detection in a future superoutburst — well within reach of small-aperture
time-domain photometry once a triggered alert is set up. Alternative classifications:
- *U Gem subtype*: less likely given the observed long-duration outburst; U Gem outbursts
  are typically ~10-20 d and don't show pronounced super-cycles.
- *Z Cam subtype*: requires occasional standstills; nothing in the ZTF data suggests a
  standstill behavior (no flat-mag periods >50 d at intermediate brightness).
- *Nova-like / VY Scl*: ruled out by the persistent quiescent state (CV is consistently faint
  between outbursts, not always-bright).

## 7. Component mass estimates

**Eclipse geometry constraints**:

For an eclipsing CV at P_orb = 3.013 hr with a near-total eclipse (depth ≥ 71%, duty cycle
~18%), the inclination i must be near 90°. Applying the standard Knigge+ 2011 CV donor sequence
at this period:

| Constraint | Value | Source |
|---|---|---|
| Period gap evolution | Donor near the upper-gap boundary | Knigge 2011 |
| Expected M_donor (semi-empirical) | 0.20–0.30 M_⊙ | Knigge 2006/2011 (Donor sequence) |
| Expected R_donor / R_⊙ | 0.27–0.32 | Knigge 2011 (Roche-filling at upper gap) |
| Expected M_WD (default CV mean) | 0.79–0.83 M_⊙ | Zorotovic+ 2011; Knigge+ 2022 |
| Mass ratio q = M_2 / M_1 | 0.25–0.38 | derived |
| Expected eclipse FWHM (φ) | 0.04–0.06 | Bailey 1979, Wood+ 1992 |
| Observed eclipse FWHM (φ) | ~0.035 (BLS dur ≈ 18 min from pipeline) | this work |
| Expected i for total eclipse | ≥ 78–82° | Bailey 1979 |
| Lower bound on i from depth | ~80° | this work (from 71% median depth) |

**Provisional mass estimates** (default Knigge+ 2011 priors at P_orb = 3.013 hr):

| Quantity | Value (median) | 1σ range | Method |
|---|---:|---:|---|
| M_WD | 0.80 M_⊙ | 0.70–0.90 M_⊙ | CV-population prior (Zorotovic 2011) |
| M_donor | 0.25 M_⊙ | 0.20–0.30 M_⊙ | Knigge+ 2011 donor sequence at P=3.0 hr |
| R_donor | 0.30 R_⊙ | 0.27–0.32 R_⊙ | Knigge+ 2011 |
| Mass ratio q | 0.31 | 0.25–0.38 | derived |
| Orbital separation a | 1.05 R_⊙ | 0.99–1.10 | Kepler's 3rd at M_tot = 1.05 M_⊙ |
| K_donor (radial velocity semi-amplitude) | 250 km/s | 210–290 | inclination-dependent |
| K_WD | 80 km/s | 65–95 | derived |
| i (inclination) | 84° ± 4° | 80–88° | eclipse depth + duty cycle |
| Donor SpT (Knigge+ 2011) | M3-M4V | — | photometric (no spectroscopy yet) |

These priors will be replaced by direct measurement once spectroscopy is in hand (donor SpT
from photometric decomposition; M_donor and i from eclipse light-curve modeling à la
Wood+ 1992 / Littlefair+ 2014). The eclipse depth, duty cycle, and pulse profile observed
in TESS are *fully consistent* with these defaults — and the period-gap location strongly
constrains the donor properties even before spectroscopy.

### Open follow-up

1. **High-resolution quiescent spectroscopy** (X-shooter at VLT, ~1 hr open-shutter,
   continuous coverage of one orbit at G ≈ 20). Would deliver:
   - Hα double-peaked emission profile (FWZI, vsini)
   - HeI/HeII line ratios — disk vs. magnetic CV
   - WD core spectrum visible at mid-eclipse (when disk is hidden) — Teff_WD via Balmer wing fit
   - Donor SpT from K-band CaII Triplet velocities (Knigge+ 2011 donor calibration)
   - Direct K_donor measurement from emission lines → M ratio q via Roche-lobe geometry

2. **Eclipse timing campaign** (small-aperture 1-m, ~10 nights over a year):
   - Pin the orbital period to σ_P < 0.1 s via per-eclipse mid-point fits
   - Look for period derivatives (dP/dt) and ETV/LTT signals indicating tertiary
   - The deep, sharp eclipse (~ 30 s ingress at high inclination) gives σ_T0 ~ 1-2 s per
     eclipse — ETV detection threshold ~ 10 s with a 50-eclipse campaign

3. **Triggered photometry of next outburst** (alert via ASAS-SN or AAVSO, then schedule
   2-night intensive coverage):
   - Confirm or rule out **superhumps** during a future superoutburst → SU UMa subclass
     locked, ε_SH = (P_SH - P_orb)/P_orb measurement → q via Patterson 2005 calibration

4. **eROSITA-DE DR2 cross-match** (expected 2027 release):
   - DR1 has no detection; DR2 baseline + sensitivity may catch quiescent disk X-ray
     emission L_X ~ 10^30-31 erg/s

5. **HST/COS UV spectrum** (1-2 orbits at G=20 quiescent, eclipse-resolved):
   - The bare-WD Balmer wing in the FUV is a direct probe of Teff_WD and log(g)_WD
   - GALEX has no detection — the only way to access the UV at this brightness is HST/COS

6. **Multi-sector TESS FFI extraction** (QLP / eleanor for S5, S32 already-observed):
   - Three sectors spanning 2018-2025 = 7 yr baseline → period precision improvement
     by ×10-100; superhumps detection in archived superoutbursts; possible ETV in archived
     eclipses; outburst statistics over 7 yr (with the ZTF 6 already counted)

### Risk assessment

The detection is robust against:
- **Confused source / blending**: clean Gaia DR3 cone search returns one source at 0.77″
  separation; no near neighbors in Pan-STARRS DR1 PSF list within 3″.
- **Period aliasing**: 4-day ZTF cadence × 7.2-yr baseline produces dense alias structure;
  the 180-min BLS detection has power ≥ 43,000× the median noise level and is also
  recovered by TESS BLS at 180.4 min (independent telescope, independent reduction).
- **Gaia QSO false-positive**: `in_qso_candidates = True` and `classprob_dsc_combmod_quasar = 0.994`
  reflect a documented DSC failure mode where blue + variable point sources are misclassified
  as quasars (Pala+ 2020; Inight+ 2023a). The CV classification is *primary* (from CSS outburst
  detection + multi-survey colors + period detection + eclipse) and *overrides* the DSC label.
- **Outburst contamination of fold**: removed via flux-mode filtering (this work, §4); the
  per-eclipse depth measurement of 71% quiescent is independent of the phase-fold.

The detection is *not* yet robust against:
- **Single TESS sector limitation**: S5 and S32 FFI data should be extracted to lengthen
  the eclipse-timing baseline and confirm period stability. This is the highest-priority
  follow-up.
- **No spectroscopic CV confirmation**: while the photometric, color, and variability
  signatures are unambiguous, a single quiescent emission-line spectrum would close the
  classification with no remaining ambiguity.
