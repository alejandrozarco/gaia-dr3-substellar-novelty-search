### 2026-05-31 — F#33 NSS period-confidence filter applied (the operative CORRECTION here)
- **Did:** A QA audit found the producer never pulled the Gaia DR3 `nss_two_body_orbit.flags` bitmask. Re-derived all `data/derived/main_hunt_derived_v2*` parquets with new `flags`/`filter33_v2`/`nss_period_nonsignificant` columns.
- **Found:** this source carries **bit 13 = NO_SIGNIFICANT_PERIODS_CAN_BE_FOUND** (Gaia's own "period confidence below threshold"). Because M₂ scales with the period, a non-significant period makes f(M) unreliable. F#33 down-tiers AstroSpectroSB1-with-bit-13 to "Tier-2 (NSS period non-significant — needs corroboration)" (the astrometric orbit still constrains the period, so it is a caution, **not** a hard FAIL as for pure SB1). This compounds the already-weak external corroboration. Project-wide, F#33 moved 79 Tier-1 NS + 1 Tier-1 BH → Tier-2.
- **Provenance:** dossier banner:4; CANDIDATES.md:53; `/tmp/sb1_flags_audit_2026_05_31.md`; refs Gaia DR3 datamodel, Bashi+2022 (MNRAS 517,3888).
