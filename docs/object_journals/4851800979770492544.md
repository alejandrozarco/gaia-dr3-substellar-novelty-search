- **Found:** A totally (or near-totally) eclipsing 0.31-Msun DA white dwarf with P = 108.04 min, eclipse length <= 5 min, and a red-dominated 6% reflection effect: a white dwarf + M-dwarf/brown-dwarf post-common-envelope eclipsing binary, uncatalogued. Uncatalogued. Next: time-resolved spectroscopy for masses; eclipse timing baseline already 10 yr.
