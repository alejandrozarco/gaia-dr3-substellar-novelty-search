## Entry log
*Append-only, chronological.*

### 2026-05-28 — HGCA PMa hunt surfaces it as a "58 Msun BH"
- **Did:** ranked the HGCA Brandt 2021 chi^2>25 AND no-NSS pool by M2_med; this source topped at 58 Msun (fiducial P=11.6 yr) from inverting the 41.47 mas/yr PMa amplitude as a single unresolved companion.
- **Found:** M2 is a steep function of the assumed period (P=3 yr -> ~17 Msun; P=11.6 yr -> ~58 Msun; saturates >200 at long P) — all of which assume the PMa is from ONE unresolved companion. chi^2=134 (snrPMa~11.6).
- **Provenance:** dossier `CD-46_10032A_DOSSIER_2026_05_28.md` §3/§5; HGCA PMa Hunt 2026-05-28.

### 2026-05-28 — DEMOTION: known visual double + Kervella stellar M2 + RUWE (Kervella/WDS correction)
- **Did:** ran the WDS 30" cone + Gaia DR3 2"/10" cone + RUWE check + Kervella H2G2 lookup (the demote criteria the 7-step novelty protocol omits).
- **Found:** SIMBAD lists **HDS 2168A** and WDS resolves an 8.1" companion (G=11.88) — a known Hipparcos double. **Kervella H2G2 gives BinH2G2=1 and M2(5 AU)=423 M_J = 0.34-0.54 Msun — a stellar M-dwarf, not a BH** (Kervella's kinematic period prior centres near a few years, vs the hunt's 11.6-yr bin). RUWE=3.05 (>> 1.4 clean threshold) indicates an additional unresolved inner perturber. Honest reading: hierarchical system, residual PMa from an ~0.4 Msun M-dwarf at P~3-6 yr. No X-ray (rules out a 261-pc 58-Msun accreting BH), no radio. The automated 7-step protocol called it TRULY_NOVEL — correct (it is in no published BH/triple/planet catalog) but "novel" != "publication-grade BH"; the HDS entry + RUWE both predate the candidate. Operational lesson: apply WDS cone + 2" cone + RUWE>2 BEFORE computing the M2 headline.
- **Provenance:** dossier top banner + §7/§10; CANDIDATES.md:183; companion to HD 37419 in the same Pile-A negative-control set.
