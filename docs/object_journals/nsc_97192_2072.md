## ATLAS independently resolves the rise (task 5009238, 3,920 good epochs, 2015-10 → 2025-11)

**Read the difference photometry correctly.** ATLAS forced photometry is differential
against a static reference. The late-era stack gives **−1.49 ± 0.33 µJy** where an
r = 20.13 source would be +32.2 µJy — which naively "refutes" the bright state. It does
not: the ATLAS reference was built while the source was **already bright**, so a constant
source yields zero difference by construction (implied reference 33.7 µJy = mag 20.08).
The signal is in the **early negative flux** — a deficit relative to a bright reference IS
the faint state.

| era | n | difference (µJy) | reconstructed source | mag_o |
|---|---|---|---|---|
| 2015-10 → 2016-12 | 103 | **−19.95 ± 3.56** | 13.7 µJy | **21.05** |
| 2017-01 → 2018-04 | 336 | −5.82 ± 1.04 | 27.9 µJy | 20.29 |
| 2018-05 → 2019-12 | 386 | −1.25 ± 0.79 | 32.5 µJy | 20.12 |
| 2020-01 → 2025-11 | 2186 | −1.70 ± 0.34 | 32.0 µJy | 20.14 |

120-day bins place the rise in **2016**: 21.93 (2016-04) → 20.46 (2016-07) → 20.25
(2017-07) → flat thereafter.

**Model-independent statement** (no assumption about the reference level): ATLAS shows a
**20 µJy brightening at 5.6σ between 2015–16 and 2018**, on a different telescope, in a
different filter, with an independent reduction from ZTF.

*Caveat:* ATLAS `o` (~560–820 nm) is not Sloan r, so the absolute mag_o values carry a
colour term — especially in the red faint state. The **differential** rise is robust; the
reconstructed absolute magnitudes are indicative.

## Assessment

**Best reading: a turn-on / changing-look AGN at z ≈ 1**, which brightened ~1.9 mag in
rest-frame UV around 2015–2016 and has remained in the high state for 8+ years.
Supporting: extended red host, quasar-level luminosity, AGN-like W1−W2, and a mid-IR

## CONFIRMED PROBLEMS — corrections applied

**1. "Dust echo" is WITHDRAWN. The timing forbids it.**
An echo must LAG the illuminating continuum. W1 was already rising well before the optical
rise: 16.067 (2015-04) → 15.852 (2015-10) → 15.630 (2016-04), while the reconstructed ATLAS
optical rise falls between 2016-04 and 2016-07. **The infrared onset precedes, or at best
overlaps, an inadequately sampled optical onset — it does not establish a positive lag.**
Correct wording: *possible infrared brightening, coincident in epoch, lag not demonstrated*.
(The 0.57 mag change is substantial and still needs a specific instrumental explanation if
it is not astrophysical — but it is not evidence of reprocessing.)

**2. LS DR10 and NSC are NOT independent — same exposures.**
`mjd_min = 57021.28, mjd_max = 57032.32` (2014-12-30 → 2015-01-10) — the identical MJDs as
the NSC `meas` rows (r at 57021.282, z at 57032.317). LS DR10 here is a re-reduction of the
same DECam data, not corroboration. This also dissolves the apparent LS-vs-ZTF conflict:
LS measured the FAINT state.
**The only genuinely independent faint-state measurement is SDSS (~2000s), r = 22.09 ± 0.27
— a marginal detection.**

**3. LS DR10 morphology rests on ONE exposure per band.**
`nobs_g = nobs_r = nobs_z = 1`, `psfsize_r = 1.37″`. `shape_r = 0.393 ± 0.028″` is formally
14σ from zero and `fracflux_r = 0.0008` confirms no neighbour contamination, but a
single-exposure REX classification at ~21σ total SNR is not a robust extension measurement.
SDSS `class = 3` is likewise marginal (r error 0.27). **"Resolved host" is supported but not
secure.**

**4. Novelty wording was wrong.** The object IS catalogued — in SDSS, NSC and LS DR10. What
is unreported is its **variability / AGN candidacy**, not its existence. Catalogue
non-matches establish neither class nor literature novelty. *NED was attempted and TIMED
OUT — not checked.* VarWISE not checked.

**5. ATLAS epoch counts reconciled** (reviewer noted the quoted eras sum to 3,011, not
3,920): 3,011 o-band inside the four quoted windows + 905 c-band (not used) + 4 in window
gaps = 3,920 good epochs. Now stated explicitly.

**6. W1−W2 discrepancy is UNRECONCILED.** LS DR10 forced gives W1−W2 = 0.49 (Vega);
NEOWISE single-exposure medians give ≈ 0.8–1.2. Different epochs and source attribution;
the difference is not explained. Do not quote either as an AGN colour diagnostic until it is.

## STANDING CAVEATS the review sharpened

- **The ATLAS reconstruction is physically plausible but not statistically established.**
  It assumes reference flux = ZTF bright flux − late difference, i.e. it uses ZTF to
  calibrate ATLAS. Time and reference configuration are confounded. The −20 µJy deficit is
  ~60% of the adopted source flux, so multiplicative calibration error cannot produce it,
  but **additive sky/subtraction residuals can, and their uncertainty does not necessarily
  shrink as 1/√N**; `chi/N < 4` does not test this. Needed: blank-position and
  non-variable-source controls, stacked early/late difference stamps (a centred PSF-shaped
  negative residual, not a table of numbers), and per-night error grouping.
- **The 64σ calibration control tests calibration, not attribution.** Bright stellar
  controls do not establish that SDSS, NSC, ZTF and WISE assign the same light to the same
  physical component of an extended source. *The reviewer's own counterweight: a clean
  isolated 0.39″ source does not routinely acquire a 2-mag discrepancy from PSF-vs-total
  photometry, and an instrumental explanation would ALSO require an ATLAS subtraction
  problem and a WISE problem.* Unexcluded null hypothesis, not a demonstrated explanation.
- **Host dilution cannot rescue a flat light curve**: if the r-band brightening is real and
  the host constant, the faint-state total bounds the host at ~13–17% of the bright state.

## NEW TESTS RUN HERE (not from the review)

**Intrinsic variability, using REAL per-epoch errors** (the review correctly noted that
assuming 0.15–0.20 mag spans opposite conclusions):

| | excess variance σ |
|---|---|
| **candidate** (n=442, median zr 20.128, obs sd 0.184, median err 0.170) | **0.070 mag** |
| 15 control stars, same magnitude & field | median **0.032**, max **0.086** |

The candidate shows ~2.2× the typical control star's excess variance, but sits **inside the
control range**. Marginal excess: weakly consistent with low-amplitude AGN variability,
**neither a detection nor a falsification**. Note at z ≈ 1, 8 observer-frame years are only
~4 rest-frame years, and there is no universal minimum variability every AGN must exceed.

**Mid-IR excludes a Galactic cataclysmic variable.** Bright state r(Vega) − W1(Vega) ≈ 4.55.
A CV (hot disk, no dust) would sit at ~0.5–2, i.e. W1 ≈ 18.5 — about 3 mag fainter than the
observed W1 = 15.4, which NEOWISE detects in 180 exposures. An M dwarf matches the colour
but is excluded by the absent Gaia source, the null proper motion (SDSS→NSC shift 0.281″
over ~11 yr, consistent with zero), and by not brightening 1.9 mag for 8 years.
**This is why the object is not VSX-eligible under any reading tested.**

### Amplitude: bracketed, not pinned
