  its object link from the identical query).
- Clean in **SIMBAD (10″), VSX, Milliquas, GCVS, Chen+2020, DES DR2**. No SDSS/DESI spectrum.

This is the lane's core premise demonstrated: a *sustained* state change is invisible to
every search that works within one survey's difference images, and is only recoverable by
comparing a deep archival epoch against a modern one.

## Assessment

**Best reading: a turn-on / changing-look AGN at z ≈ 1**, which brightened ~1.9 mag in
rest-frame UV around 2015–2016 and has remained in the high state for 8+ years.
Supporting: extended red host, quasar-level luminosity, AGN-like W1−W2, and a mid-IR
echo coincident with the optical change.

Excluded or disfavoured:
- **Supernova** — excluded; SNe decline, this is flat for 8 yr.
- **Classic TDE** — disfavoured; decay timescales are months–years, not 8 flat years.
- **Blend** — excluded; no LS DR10 source within 5″, ZTF centroid 0.07″ from the target.
- **Threshold artifact** — excluded; measured mag vs frame-depth slope is **+0.19**
  (pure artifact ≈ 1.0; a known-real control star gives −0.006), and on deep frames
  (limit 21.0–21.5, detection secure by 0.8–1.3 mag) it measures a consistent 20.23.
- **Stellar/Galactic** — disfavoured; resolved in LS DR10 and SDSS, no Gaia counterpart.
- **Tile-level photometric systematic — EXCLUDED by direct control.** Both near-threshold
  objects in the run fell in the same tile (Dec ≈ +0.55–0.59), the same pattern that proved
  to be an artifact in the v1 pilot, so it was tested rather than assumed. 22 ordinary NSC
  stars (r = 19.0–20.5, class_star > 0.8) in that tile were compared against their own ZTF
  zr medians:

  | | |
  |---|---|
  | median NSC r − ZTF zr | **+0.069 mag** |
  | scatter (stdev) | **0.037 mag** |
  | full range | +0.00 to +0.16 |

  NSC and ZTF agree to <0.1 mag in this tile. The candidate's **+2.44 mag** offset is
  **64σ** from that control distribution.
  *Stated limit:* controls necessarily sit at r = 19.0–20.5, because ZTF cannot measure
  r ≈ 22 sources at all, so a faint-end NSC bias is not directly testable this way.
  It is addressed instead by **SDSS DR16 independently measuring r = 22.09** at this
  position — two independent surveys agree on the faint state.
